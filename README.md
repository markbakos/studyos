# StudyOS

Local-first personal study operating system built with React, TypeScript, Vite, and Tailwind CSS.

The current repository contains the application foundation. The product contract and engineering plan live in [`context/README.md`](context/README.md).

```bash
npm install
npm run dev
```

Run `npm run check` before committing. Use `npm run build` for a production bundle and `npm run preview` to serve it locally.

## Current status

The web foundation builds successfully. Product features, persistence, planning, and PWA support are specified but not yet implemented; see [`context/ROADMAP.md`](context/ROADMAP.md).
